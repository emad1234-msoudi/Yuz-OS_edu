## 📚 درباره Yuz-OS Edu

> «راهنمای اینگلیسی پروژه: [README.md](/README.md)»

Yuz-OS Edu یک سیستم‌عامل آموزشی و فریم‌ورک استقرار (Deployment Framework) است که به‌طور ویژه برای مدارس، آزمایشگاه‌ها، معلمان و دانش‌آموزان طراحی شده است.

هدف این پروژه، ساخت یک توزیع لینوکسی دیگر نیست؛ بلکه تلاش می‌کند به یک مشکل واقعی در محیط‌های آموزشی پاسخ دهد:

«چگونه می‌توان بدون تعویض تمام سخت‌افزارهای موجود، کلاس‌های کامپیوتر مدارس را به محیطی مدرن و کارآمد تبدیل کرد؟»

بسیاری از مدارس و مراکز آموزشی همچنان از رایانه‌های قدیمی استفاده می‌کنند، زیرا ارتقای سخت‌افزار هزینه‌بر است. از سوی دیگر، نصب، پیکربندی و نگهداری نرم‌افزارهای آموزشی روی ده‌ها رایانه، زمان و نیروی انسانی زیادی نیاز دارد.

Yuz-OS Edu برای حل این چالش، یک بستر آموزشی کامل بر پایه Debian 13 فراهم می‌کند که مجموعه‌ای از نرم‌افزارهای آموزشی منتخب، محیط دسکتاپ سفارشی، ابزارهای خودکار استقرار و یک فریم‌ورک ساخت ماژولار را در کنار یکدیگر ارائه می‌دهد.

این پروژه به مدارس کمک می‌کند تا رایانه‌های موجود خود را با کمترین هزینه و پیچیدگی، به ایستگاه‌های کاری آموزشی مدرن تبدیل کنند.

## 🎯 مأموریت پروژه

Yuz-OS Edu تنها با یک هدف اصلی توسعه یافته است:

«فراهم کردن آموزش دیجیتال باکیفیت برای تمام مدارس، با استفاده از نرم‌افزارهای آزاد و متن‌باز (FOSS).»

این پروژه تلاش می‌کند با ایجاد یک بستر آموزشی یکپارچه، کیفیت محیط‌های یادگیری را ارتقا دهد و در عین حال هزینه‌های مدارس را کاهش دهد.

**از مهم‌ترین اهداف پروژه می‌توان به موارد زیر اشاره کرد:**

- کاهش هزینه‌های استقرار و نگهداری نرم‌افزارها
- افزایش طول عمر رایانه‌های قدیمی
- بهبود تجربه کاربری در کلاس‌های درس
- فراهم کردن ابزارهای آموزشی تعاملی برای دانش‌آموزان
- کمک به معلمان برای برگزاری کلاس‌های دیجیتال جذاب‌تر
- گسترش فرهنگ استفاده از نرم‌افزارهای آزاد و متن‌باز (FOSS)

Yuz-OS Edu تنها مجموعه‌ای از نرم‌افزارها نیست؛ بلکه محیطی آموزشی است که در آن نرم‌افزارها، طراحی رابط کاربری، پیکربندی سیستم و ابزارهای استقرار همگی در کنار یکدیگر یک پلتفرم آموزشی یکپارچه را تشکیل می‌دهند.

## ✨ چه چیزهایی در Yuz-OS Edu v1.2.0 جدید است؟

Yuz-OS Edu از یک Debian Live Image سفارشی، به یک پروژهٔ سیستم‌عامل آموزشی ماژولار و مبتنی بر هویت یکپارچه تبدیل شده است.

این پروژه اکنون یک چارچوب ساختاریافته برای ایجاد توزیع‌های آموزشی سفارشی فراهم می‌کند؛ توزیع‌هایی که از معماری سیستم، هویت بصری و گردش‌کار استقرار یکپارچه برخوردار هستند.

نسخهٔ 1.2.0 هویت نهایی Yuz OS، پایداری بهتر فرایند Build، برندینگ دقیق‌تر سیستم و تجربه‌ای یکپارچه‌تر از محیط دسکتاپ را در Live Environment و سیستم نصب‌شده ارائه می‌کند.

**این نسخه شامل موارد زیر است:**

- نهایی‌سازی Metadata پروژهٔ Yuz OS
- ایجاد معماری یکپارچهٔ Branding
- بهبود یکپارچه‌سازی GRUB و Plymouth
- افزودن بسته‌های اختصاصی Branding برای سفارشی‌سازی سراسری سیستم
- مدیریت قابل‌اعتمادتر APT Mirrorها در طول فرایند Build
- بهبود فرایند Build و Deployment
- یکپارچه‌سازی برنامه‌های شخص ثالث مانند `VS Code` و `OnlyOffice`
- بهینه‌سازی سیستم با پیکربندی `ZRAM` و `swap`
- بهبود سفارشی‌سازی محیط دسکتاپ GNOME
- تولید خروجی‌های نهایی Release شامل ISO، فایل `zsync` و Checksumها

Yuz-OS Edu v1.2.0 پایه‌ای پایدار برای هویت یکپارچهٔ پروژه و توسعهٔ آیندهٔ آن ایجاد می‌کند.

**یک پروژه. یک هویت.**

## 🏗 معماری پروژه

برخلاف بسیاری از پروژه‌های Remaster لینوکس که تنها یک فایل ISO موجود را تغییر می‌دهند، Yuz-OS Edu سیستم ساخت ماژولار اختصاصی خود را بر پایه Debian Live Build توسعه داده است.

این معماری پروژه را به چندین لایه مستقل تقسیم می‌کند تا نگهداری، توسعه و سفارشی‌سازی هر بخش ساده‌تر شود.

```
Yuz-OS Edu
│
├── Documentation
├── Branding Assets
├── Release Packages
├── Testing
└── Live Build Framework
    │
    ├── Yuz Builder
    ├── Modular Framework
    ├── Build Modules
    ├── Configuration
    ├── Debian Live Build
    └── ISO Output
```

این طراحی باعث می‌شود هر زیرسامانه بتواند بدون ایجاد اختلال در سایر بخش‌های پروژه، به‌صورت مستقل توسعه پیدا کند.

## ⚙ فریم‌ورک Yuz Builder

یکی از مهم‌ترین قابلیت‌هایی که در نسخه‌های 1.1.x معرفی شده، ایجاد Yuz Builder Framework است.

به‌جای آنکه کاربر مجبور باشد تمام تنظیمات Debian Live Build را به‌صورت دستی انجام دهد، Yuz Builder کل فرایند ساخت را به‌صورت خودکار مدیریت می‌کند.

**این فریم‌ورک وظایفی مانند موارد زیر را انجام می‌دهد:**

- بررسی و اعتبارسنجی محیط ساخت
- بررسی منابع سخت‌افزاری سیستم
- نصب وابستگی‌های موردنیاز
- آماده‌سازی محیط Build
- بارگذاری اجزای فریم‌ورک
- اجرای ماژول‌های انتخاب‌شده توسط کاربر
- اجرای Debian Live Build
- تولید فایل نهایی ISO

به‌جای ویرایش ده‌ها فایل پیکربندی، کاربر تنها با یک راهنمای مرحله‌به‌مرحله (Setup Wizard) تعامل دارد که تمام مراحل موردنیاز را به‌صورت خودکار آماده می‌کند.

## 🚀 خط لوله ساخت (Build Pipeline)

فرایند ساخت سیستم‌عامل از یک Pipeline ساختاریافته پیروی می‌کند.

```
setup.sh
      │
      ▼
بررسی سیستم
      │
      ▼
نصب وابستگی‌ها
      │
      ▼
راه‌اندازی فریم‌ورک
      │
      ▼
راهنمای انتخاب ماژول‌ها
      │
      ▼
اجرای ماژول‌ها
      │
      ▼
Debian Live Build
      │
      ▼
اجرای ماژول‌های زمان Build
      │
      ▼
تولید Hybrid ISO
```

**این ساختار مقدار بسیار زیادی از عملیات دستی موردنیاز برای تولید نسخه‌های جدید سیستم‌عامل را حذف کرده است.**

نسخه 1.1.x یکی از مهم‌ترین قابلیت‌های پروژه را معرفی می‌کند:

مخزن آفلاین داخلی Flatpak

به‌جای آنکه پس از نصب سیستم به اینترنت نیاز باشد، Yuz-OS Edu دارای مخزن Flatpak اختصاصی خود است.

- کاهش زمان استقرار سیستم

این قابلیت به‌ویژه برای مدارسی که دسترسی محدود یا ناپایداری به اینترنت دارند، بسیار ارزشمند است.

## 🎨 تجربهٔ دسکتاپ سفارشی

Yuz-OS Edu صرفاً مجموعه‌ای از نرم‌افزارها نیست.

محیط دسکتاپ با دقت طراحی و سفارشی‌سازی شده است تا تجربه‌ای یکپارچه، متمرکز و قابل‌دسترس برای استفاده‌های آموزشی فراهم کند.

این سیستم، سفارشی‌سازی GNOME، یک زبان بصری یکپارچه و اجزای دسکتاپ انتخاب‌شده را با یکدیگر ترکیب می‌کند تا محیط Live و سیستم نصب‌شده، هویت یکسانی داشته باشند.

**تجربهٔ دسکتاپ شامل موارد زیر است:**

- تم GTK گرافیتی `Graphite GTK Theme`
- تم آیکون `Colloid Icon Theme`
- والپیپرهای اختصاصی Yuz OS
- مجموعهٔ فونت‌های فارسی
- محیط دسکتاپ سفارشی‌شدهٔ GNOME
- افزونه‌های ازپیش‌پیکربندی‌شدهٔ GNOME
- ظاهر بهبودیافتهٔ GDM
- Branding یکپارچهٔ دسکتاپ
- چیدمانی متمرکز برای فرایندهای آموزشی
- برنامه‌های منتخب برای بهره‌وری و یادگیری

Assetهای بصری و پیکربندی دسکتاپ در فرایند Deployment یکپارچه شده‌اند تا هر سیستم تولیدشده، تجربه‌ای یکسان و هماهنگ از Yuz OS ارائه کند.

## 🛠 پیش‌نیازهای ساخت (Build Requirements)

به‌منظور تضمین تولید نسخه‌های قابل تکرار (Reproducible Builds)، محیط ساخت پروژه به‌صورت استاندارد تعریف شده است.

**سیستم‌عامل پشتیبانی‌شده**

- Debian GNU/Linux 13 (Trixie)
- معماری ۶۴ بیتی (amd64)

**حداقل سخت‌افزار موردنیاز**

- 6 گیگابایت حافظه RAM
- ۲۰ تا ۳۰ گیگابایت فضای خالی دیسک
- اتصال پایدار به اینترنت

**سخت‌افزار پیشنهادی**

- ۸ گیگابایت RAM یا بیشتر
- حافظه SSD
- پردازنده چند هسته‌ای

>[!IMPORTANT]
>مدت‌زمان ساخت سیستم‌عامل به توان سخت‌افزار و سرعت اینترنت بستگی دارد و معمولاً بین ۱ تا ۲ ساعت زمان نیاز خواهد داشت.

## 🚀 ساخت Yuz-OS Edu

فرآیند ساخت پروژه تا حد امکان ساده طراحی شده است.

**ابتدا مخزن پروژه را دریافت کنید:**

```bash
git clone https://github.com/emad1234-msoudi/Yuz-OS_edu.git
```

**سپس وارد پوشه ساخت شوید:**

```bash
cd Yuz-OS_edu/live-build
```

**به فایل Setup مجوز اجرا بدهید:**

```bash
chmod +x setup.sh
```

**سپس راهنمای نصب را اجرا کنید:**

```bash
./setup.sh
```

**Yuz Builder به‌صورت خودکار مراحل زیر را انجام می‌دهد:**

## 🎨 برندینگ (Branding)

پروژه Yuz-OS Edu از یک هویت بصری یکپارچه برخوردار است که به‌طور ویژه برای یک سیستم‌عامل آموزشی طراحی شده است.

سیستم Branding تنها به دسکتاپ محدود نمی‌شود؛ بلکه در سراسر چرخهٔ استفاده از سیستم، از نخستین صفحهٔ Boot تا تجربهٔ Login و نشست نهایی Desktop، گسترش پیدا می‌کند.

**سیستم Branding شامل موارد زیر است:**

- لوگوی اختصاصی پروژهٔ Yuz OS
- اطلاعات (Metadata) نهایی‌شدهٔ پروژه
- بسته‌های اختصاصی Branding
- تم GTK گرافیتی `Graphite GTK Theme`
- تم آیکون `Colloid Icon Theme`
- والپیپرهای اختصاصی
- مجموعهٔ فونت‌های فارسی
- سفارشی‌سازی دسکتاپ GNOME
- سفارشی‌سازی تم GRUB
- تم بوت Plymouth
- برندینگ (Branding) بصری در زمان Boot
- سفارشی‌سازی GDM و صفحهٔ Login
- یکپارچه‌سازی Startup Sound

اجزای اصلی Branding در بسته‌های اختصاصی سازمان‌دهی شده‌اند تا نگهداری، استفادهٔ مجدد و توسعهٔ هویت بصری در Buildهای آیندهٔ Yuz OS ساده‌تر شود.

این رویکرد یکپارچه تضمین می‌کند که Yuz OS Edu در تمام مسیر کاربر، هویتی منسجم و یکسان ارائه دهد:

مسیری در : **Boot. Login. Desktop.**

**یک پروژه. یک هویت.**
