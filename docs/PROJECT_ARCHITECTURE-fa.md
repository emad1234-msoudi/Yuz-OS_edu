## 📖 معرفی

Yuz-OS یک توزیع آموزشی لینوکس است که بر پایه Debian Live Build توسعه داده می‌شود.

در Yuz-OS، به‌جای ایجاد تغییر مستقیم روی Debian، یک چارچوب (Framework) ماژولار طراحی شده است که تمام مراحل ساخت فایل ISO را به‌صورت خودکار مدیریت می‌کند.

هدف این سند، توضیح ساختار کلی پروژه و ارتباط اجزای مختلف با یکدیگر است.

این فایل مستندات آموزشی برای برنامه‌نویسی نیست؛ بلکه نقشه‌ی معماری پروژه محسوب می‌شود.

## 🚀 setup.sh

ورودی اصلی (Entry Point) پروژه است.

**وظایف آن:**

- بررسی وضعیت سیستم
- آماده‌سازی محیط ساخت
- بارگذاری Framework
- اجرای ماژول‌ها
- اجرای Debian Live Build
- تولید فایل ISO نهایی

---

## 🧩 Framework

```
scripts/framework/

check.sh
env.sh
filesystem.sh
log.sh
package.sh
runtime.sh
ui.sh
```

Framework مجموعه‌ای از ابزارها و توابع مشترک پروژه است که توسط همه‌ی ماژول‌ها استفاده می‌شوند.

**نمونه وظایف:**

- ثبت گزارش (Logging)
- رابط کاربری ترمینال (UI)
- مدیریت محیط اجرا
- مدیریت فایل‌ها
- مدیریت بسته‌ها
- بررسی پیش‌نیازهای سیستم

خود Framework هیچ عملیات ساختی انجام نمی‌دهد و فقط امکانات موردنیاز را در اختیار ماژول‌ها قرار می‌دهد.

---

## 🔧 ماژول‌ها (Modules)

```
scripts/modules/

build/
flatpak/
...
```

هر ماژول مسئول انجام یک وظیفه‌ی مشخص در فرایند ساخت است.

**نمونه‌ها:**

- آماده‌سازی محیط ساخت
- ساخت مخزن آفلاین Flatpak
- ماژول‌های سفارشی‌سازی سیستم در آینده

Framework ماژول‌ها را اجرا می‌کند و ماژول‌ها نیز به‌صورت مستقل طراحی شده‌اند و مستقیماً یکدیگر را فراخوانی نمی‌کنند.

---

## 📦 پیکربندی (Configuration)

```
config/

hooks/
includes.chroot/
package-lists/
packages.chroot/
...
```

این بخش شامل تمام فایل‌هایی است که مستقیماً توسط Debian Live Build استفاده می‌شوند.

**از جمله:**

- فهرست بسته‌های نرم‌افزاری
- بسته‌های محلی (".deb")
- Hookهای Live Build
- قالب‌ها (Themes)
- آیکون‌ها
- تنظیمات Calamares
- فایل‌های پیکربندی سیستم
- فایل‌هایی که مستقیماً داخل سیستم نهایی کپی می‌شوند

## 🗄 Cache

`cache/`

محل نگهداری فایل‌های موقت در هنگام ساخت پروژه.

این پوشه بخشی از خروجی نهایی نیست و در هر زمان می‌تواند حذف شود.

در صورت نیاز، دوباره به‌صورت خودکار ایجاد خواهد شد.

## 🎯 فلسفه طراحی

**سیستم ساخت Yuz-OS بر پایه چند اصل ساده طراحی شده است:**

- ماژولار (Modular)
- قابل پیش‌بینی (Predictable)
- قابل تکرار (Reproducible)
- نگهداری آسان (Maintainable)
- توسعه‌پذیر (Extensible)

هر بخش از پروژه تنها یک مسئولیت مشخص دارد و از انجام چندین وظیفه‌ی متفاوت به‌صورت هم‌زمان پرهیز می‌شود.
